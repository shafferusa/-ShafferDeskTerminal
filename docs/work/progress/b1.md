# b1: bond family, government group (13 products) + bond browser driver

Workspace: $SP/b1 (results in b1/results, sandboxes in b1/tmp, shots in b1/shots; explore.mjs + drafts/*.mjs = behaviour
exploration only: `SDT_MATRIX_TMP=$SP/b1/tmp node --disable-warning=ExperimentalWarning $SP/b1/explore.mjs $SP/b1/drafts/<x>.mjs`).
Run one product (always with `SDT_MATRIX_RESULTS=$SP/b1/results SDT_MATRIX_TMP=$SP/b1/tmp SDT_MATRIX_SHOTS=$SP/b1/shots`):
`SDT_MATRIX_PRODUCT=<id> node --disable-warning=ExperimentalWarning --test test/matrix/engine.test.js`, then
`npm run -s test:api -- --product=<id>`, then `npm run -s test:browser -- --product=<id>`.
Save after each product: `$SP/tools/save-note.sh b1 0.2 "<product> passes at engine, API and browser"` (0 points for a fix).

## Done
- `test/matrix/specs/bond-government.mjs`: header with the bond rules, helpers (EST, EDT, EST_1730, FILL, SHORT, startState,
  idle, usdCash, BOND_TICKET) and six scenarios passing at engine, API and browser:
  treasury_note, treasury_bill (Treasury owner), treasury_bond (short sale), strips, foreign_gov_bill (GBP, FX), foreign_gov_bond (JPY, FX).
- `test/matrix/drivers/browser/bond.mjs`: registration (all bond contract fields, calendars, lag, primary view, exchange/OTC,
  settlement currency), the bond ticket (Settlement field, borrow assumption, financing), `actions.owner_screens` (Treasury scope).
- Terminal fixes (each with a regression test in `test/core/bond-accrual.test.js`, 7 tests, except 8):
  1. `server/products/bond.js` accrual: interest on settled face to D + interest in unsettled trades to their settlement dates
     (was: trued down to trade date = negative income). 2. end-of-day runs older than the last coupon are skipped
     (`pos.data.accruedThrough`; was: re-accrued the old period after a coupon during catch-up). 3. coupon entitlement = face
     settled before the coupon date (`entitledFace`); a seller flat on trade date keeps a coupon it still owns.
  4. previewed settlement amount = rounded principal + rounded accrued (`economics`). 5. `terms.minDenomination` validated and
     described; `web/lib/contracts.js` bond form has "Minimum denomination (face)". 6. `bond.tradeRefusal`: a trade settling
     on or after maturity is refused (one hook line each in `server/core/packages.js` and `server/core/orders.js`).
  7. `server/core/engine.js` `markShortCollateral`: bond short collateral on clean value PLUS accrued coupon owed; short accruals
     read "Interest cost ...", the short's coupon "Coupon paid on N X sold short".
  8. `server/quant/bond.js` `couponPer100`: a FIXED coupon on ACT/365 pays rate/frequency (JGB, Canada, South Africa), not
     rate x days/365. Regression test added (8 tests in bond-accrual.test.js). Found while designing foreign_gov_bond.
  9. `bond.onPositionChange`: a trade on a coupon date after that coupon was paid scheduled the same coupon again and it was
     paid twice (found by em_local_debt, partial sale on 31 Aug). Now skips a coupon date already done for the position.
     Regression test added (9 tests in bond-accrual.test.js).
- Harness (additive): `lib/normalize.mjs` preview legs carry `accrued`; `lib/actions.mjs` `order.settle` + no-op `owner_screens`;
  `specs.test.js` audit: cash = principal + stated accrued, `settlementCheck: false` on a step; `drivers/browser.mjs`: Positions
