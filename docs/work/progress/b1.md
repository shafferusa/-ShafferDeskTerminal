# b1: bond family, government group (13 products) + bond browser driver

Workspace: $SP/b1 (results in b1/results, sandboxes in b1/tmp, shots in b1/shots; explore.mjs + drafts/*.mjs = behaviour
exploration only: `SDT_MATRIX_TMP=$SP/b1/tmp node --disable-warning=ExperimentalWarning $SP/b1/explore.mjs $SP/b1/drafts/<x>.mjs`).
Run one product (always with `SDT_MATRIX_RESULTS=$SP/b1/results SDT_MATRIX_TMP=$SP/b1/tmp SDT_MATRIX_SHOTS=$SP/b1/shots`):
`SDT_MATRIX_PRODUCT=<id> node --disable-warning=ExperimentalWarning --test test/matrix/engine.test.js`, then
`npm run -s test:api -- --product=<id>`, then `npm run -s test:browser -- --product=<id>`.
Save after each product: `$SP/tools/save-note.sh b1 0.2 "<product> passes at engine, API and browser"` (0 points for a fix).
